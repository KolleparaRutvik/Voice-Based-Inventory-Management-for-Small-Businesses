Voice-Based Inventory Management for Small Businesses
📌 Overview

Voice-Based Inventory Management is a mobile-responsive application designed to help small businesses manage their inventory using simple voice commands.

The system supports English, Telugu, Hindi, and mixed-language speech, allowing shopkeepers to manage stock with minimal typing.

🎯 Problem

Small businesses often manage inventory using notebooks, spreadsheets, memory, or messaging applications. This can result in:

Incorrect or outdated stock information

Missed low-stock products

Difficulty tracking purchases and sales

Time-consuming manual entry

Difficulty managing customer credit

Language barriers with traditional inventory applications

💡 Proposed Solution

The application provides a voice-first inventory management system where users can speak naturally to perform common inventory operations.

Example:

"5 bags biyyam add cheyyi."

The system identifies the product, quantity, unit, and operation, then asks for confirmation before making the inventory change.

Users can also ask:

"How much rice is available?"

or

"What should I order?"
